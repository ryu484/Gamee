# ByteBot Quest

A funny and colorful browser game that teaches students about computer hardware and software.

## Features
- Roblox-style blocky game UI
- Levels with XP progression
- Quiz-based learning about hardware and software
- Coins, rank upgrades, and quest log
- Bright cartoon styling and silly computer jokes

## How to run
1. Open the project folder in a browser.
2. Double-click `index.html` or serve it locally with a tiny web server.

Example local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Game concept
Students play as a robot named ByteBot and complete missions to learn:
- CPU, RAM, storage, and input/output devices
- The difference between hardware and software
- Why antivirus matters
- How computers work together as systems

## Repo structure
- `index.html` – main game page
- `styles.css` – Roblox-inspired styling
- `script.js` – game logic, levels, XP, and quiz system

Enjoy building computer brains without the actual overheating!
